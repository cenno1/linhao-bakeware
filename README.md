## Local preview
Run `python -m http.server 8080` in this folder and open `http://localhost:8080`.

## Deployment
Import the GitHub repository into Vercel. Select **Other** as the framework preset and leave the build command blank. The output directory is the repository root.

## Important content note
Product imagery and source data were compiled from the three catalogs supplied by the customer. Supplier names, factory metrics, customer logos and certification claims inside those PDFs must not be represented as universal LINHAO claims without project-specific confirmation.
