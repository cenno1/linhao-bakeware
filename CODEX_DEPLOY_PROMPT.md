# Codex instruction - upload and deploy LINHAO BAKEWARE

You are working inside the extracted `linhao-bakeware-site` folder.

1. Audit the static site for broken relative links, missing images, mobile overflow and invalid HTML.
2. Do not replace the product images or rewrite the approved brand name, company name, email or WhatsApp number.
3. Preserve the B2B positioning: no retail prices, no shopping cart and no checkout.
4. Initialize Git, create a new GitHub repository named `linhao-bakeware`, commit all files and push to the user's GitHub account.
5. Import the repository into Vercel using the **Other** framework preset. No build command is needed; serve the repository root.
6. Verify these routes after deployment: `/`, `/products`, `/customization`, `/quality`, `/about`, `/catalogs`, `/contact`, at least three `/products/*` pages, `robots.txt` and `sitemap.xml`.
7. Add the production domain `linhaobakeware.com` only after the user purchases it. Do not change Namecheap or Cloudflare DNS without explicit user approval.
8. When the domain is connected, verify HTTPS, canonical URLs, sitemap access, mobile navigation, WhatsApp links and the email inquiry flow.
9. Report the GitHub repository URL, Vercel preview URL, production URL (if connected), and any issue that still needs the user's action.

Do not copy code, text or images from usapan.com. The site may use its category clarity and professional spacing as inspiration only.
